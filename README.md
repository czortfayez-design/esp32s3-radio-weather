# ESP32-S3 Radio i Pogoda
Program radiowy z wyświetlaczem pogody dla Waveshare ESP32-S3 4.3" Touch LCD

## Funkcje
- 📻 Odtwarzanie stacji radiowych (stream MP3/AAC)
- 🌤️ Wyświetlanie pogody w czasie rzeczywistym
- 🎛️ Interfejs dotykowy z przyciskami
- 📊 Wyświetlanie temperatury, wilgotności, ciśnienia
- 🌐 Synchronizacja czasu przez NTP
- 💾 Pamięć ulubionych stacji
- 🔊 Regulacja głośności

## Hardware
- Waveshare ESP32-S3 4.3" Touch LCD
- Głośnik 8Ω 0.5W
- Zasilanie 5V

## Wymagane biblioteki
- Arduino IDE / PlatformIO
- Biblioteki dostępne w `platformio.ini`

## Instalacja
1. Klonuj repozytorium
2. Otwórz projekt w PlatformIO
3. Konfiguruj `config.h` (WiFi, API)
4. Wgraj firmware
